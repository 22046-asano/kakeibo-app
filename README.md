# Smart Kakeibo PWA (v5 - 全項目編集対応 ＆ モダンUI刷新版)

PCとスマートフォンの両方でリアルタイムに連動するクラウド家計簿Webアプリケーション（PWA対応）です。

---

## 🌟 v5 アップデート内容（全データの登録後変更対応 ＆ UI全面リニューアル）

### 1. すべての登録データの「後から編集・変更」に完全対応
- **立替金・請求予定 (`Reimbursement`) の編集**:
  - 一度登録した立替金について、区分（友達・大学・会社・彼女・家族）、相手の名前・用途、金額、立替日、回収予定日、メモ、精算状態をいつでも変更可能。
- **バイト代振込予定 (`ExpectedIncome`) の編集 ＆ 入金照合ダイアログ**:
  - 登録済みの振込予定の金額・予定日・バイト先・勤務時間メモをいつでも編集可能。
  - 「振込を確認」押下時に**金額照合ダイアログ**が表示され、実際の振込額が予定額と数百円ずれていた場合でもその場で金額を微調整して確定・家計簿へ自動記帳が可能。
- **クレジットカード決済の引き落とし日 (`billing_date`) 手動変更対応**:
  - 締め日・支払日・土日祝ルールによる自動計算に加え、明細編集モーダル内で引き落とし予定日を手動で変更・微調整（「自動計算に戻す」リセットボタン付き）が可能。
  - カード設定を変更した際、**既存のカード決済明細の引き落とし日を新ルールで一括再計算する機能**を搭載。
- **カレンダー・年間ビューからの直接編集・削除**:
  - カレンダーの日付別明細や、年間・バイト代タブの明細履歴から、月を移動することなくその場で任意の明細を編集・削除可能。
  - カレンダーで選択した日付に対して「＋ この日に記帳」で日付自動セット入力が可能。

### 2. 人気家計簿アプリ（マネーフォワード ME / Zaim / Moneytree 等）を参考にしたUI全面刷新
- **スマホ用ボトムナビゲーション ＆ PC用セグメントヘッダー**:
  - スマホでは片手親指で操作しやすい下部固定ナビゲーションバーと中央の「＋ 記帳」ボタンを採用。
- **キャッシュフロー・ヒーローカード ＆ インタラクティブSVGドーナツチャート**:
  - 当月の収支バランス、収入に対する支出率ゲージ、カード引落予定額を一目で把握。
  - ドーナツグラフやカテゴリ行をタップすると、右側の明細タイムラインを該当カテゴリで即座にフィルタリング。
- **日付グルーピング明細タイムライン**:
  - 日付ごとの小計ヘッダー付きタイムライン表示、キーワード検索、収支種別フィルタ、常時押しやすい編集・削除ボタンを配置。

## 🚀 本番環境（Vercel）への反映手順

今回のアップデートではデータベース構造（SQL）の変更は不要です。ソースコードを上書きして GitHub にプッシュするだけで反映されます。

1. `kakeibo-pwa-v5.zip` を解凍し、既存の作業フォルダ（`kakeibo-pwa`）に上書きコピーします。
2. コマンドプロンプトで以下を実行します：
   ```cmd
   git add .
   git commit -m "Update v5: full editability for all items and modern kakeibo UI overhaul"
   git push
   ```
3. 約1分で Vercel のビルドが完了し、PC・スマホの画面に反映されます。
