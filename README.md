# シンプル家計簿 クラウド (v8 - 支払予定管理・カレンダーダブルクリック記帳・123万円の壁追加版)

PCとスマートフォンの両方でリアルタイムに連動するクラウド家計簿Webアプリケーション（PWA対応）です。

## 🌟 v8 アップデート内容

### 1. 「自分が誰かに払わなくてはいけない金額（支払・返済予定）」管理機能の追加
- 「立替・振込」タブに、従来の「立替・請求（相手からもらう）」と「バイト代振込予定」に加えて、**「支払・返済（自分が払う）」タブ**を新設しました。
- 友達・大学・会社・彼女・家族の5区分ごとに、未払いの金額・支払期限・メモを記録でき、登録後の全項目編集や「もらう額 − 払う額」の差引バランス確認も可能です（データベースのSQL変更なしでそのまま既存のテーブルに保存されます）。

### 2. カレンダーの日付ダブルクリック（スマホは2回連続タップ）での直接記帳
- カレンダー上の任意の日付マスを**ダブルクリック（スマホでは素早く2回タップ）**すると、その日付が自動セットされた状態で収支入力画面が即座に開きます。

### 3. バイト代累計計算に「123万円の壁」を追加 ＆ 全壁の残額一覧表示
- 税制改正後の扶養控除基準である **「123万円の壁（基礎控除58万＋給与所得控除65万）」** をプリセットに追加しました。
- さらに、103万・123万・130万・150万・160万・178万の各ラインまでの残り金額をひと目で比較できる一覧パネルを追加しました。

## 🚀 本番環境（Vercel）への反映手順

今回のアップデートでもデータベース（SQL）の追加変更は不要です。

1. `kakeibo-pwa-v8.zip` を解凍し、既存の `kakeibo-pwa` フォルダに上書きコピーします。
2. コマンドプロンプトで以下を実行します：
   ```cmd
   git add .
   git commit -m "Update v8: add payable tracker, calendar double-click entry, and 123M tax wall"
   git push
   ```
