# シンプル家計簿 クラウド (v7 - 銀行預金つじつま合わせ補正機能 ＆ シンプル家計簿風UI版)

PCとスマートフォンの両方でリアルタイムに連動するクラウド家計簿Webアプリケーション（PWA対応）です。

## 🌟 v7 アップデート内容

### 1. 銀行預金残高の入力 ＆ 自動つじつま合わせ（残高調整金）機能
- **実際の銀行預金残高にワンタップで補正**:
  - 収入や支出の入力忘れで実際の口座残高とズレが生じた際、「預金残高を入力・補正」から現在の銀行預金残高を入力すると、これまでの計算残高との差額を自動計算します。
  - 差額は**1ヶ月前の日付（変更可能）にカテゴリー「調整金」**として自動入力され、現時点の預金残高が実際の口座残高にピタリと一致します。
- **今後のカード引き落とし金額との残高計算**:
  - 補正された現在の銀行預金残高から、**「今月これから引き落とされるカード予定額」「来月以降に引き落とされるカード予定額」**を自動で差し引き、**「カード引き落とし後の予想預金残高」**を常時メイン画面に表示します。
- **バイト代・年間収入・月間収支への影響ゼロ**:
  - 自動生成された「調整金」は、年間のバイト代集計（扶養計算）や月間の通常収入・支出・カテゴリー別円グラフから自動的に分離・除外されるため、本来の家計集計や扶養シミュレーションが狂うことはありません。

### 2. 「シンプル家計簿（Komorebi）」風UIへのリニューアル
- **温かみのあるオレンジ＆クリームホワイト配色**:
  - オレンジの貯金箱アイコン（`¥`）と視認性の高い配色に統一。
- **カレンダー＋3列収支バー＋明細リストの一体表示**:
  - カレンダー画面の上部に「収入 | 支出 | 今月の収支」の3列バーと「銀行預金残高＆今後のカード引落計算バー」を配置し、カレンダーのすぐ下に明細リストを一体表示。
- **下部5タブバー（入力・カレンダー・レポート・立替/振込・設定）**:
  - 「レポート」タブでは「月間カテゴリー別グラフ（円グラフ）」と「年間バイト代・扶養レポート」をワンタップで切り替え可能。

## 🚀 本番環境（Vercel）への反映手順

今回のアップデートではデータベース（SQL）の変更は不要です（v6のSQLを実行済みであればそのまま動作します）。

1. `kakeibo-pwa-v7.zip` を解凍し、既存の `kakeibo-pwa` フォルダに上書きコピーします。
2. コマンドプロンプトで以下を実行します：
   ```cmd
   git add .
   git commit -m "Update v7: add bank balance auto-adjustment and Simple Kakeibo UI"
   git push
   ```
