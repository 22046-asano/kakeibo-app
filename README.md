# Smart Kakeibo PWA (v6 - 本人認証＆RLS完全ロック・セキュリティ強化版)

PCとスマートフォンの両方でリアルタイムに連動するクラウド家計簿Webアプリケーション（PWA対応）です。

## 🔒 v6 セキュリティ強化内容

1. **ログイン認証画面（`AuthGate`）の導入**:
   - 未ログイン状態では家計簿画面やデータを一切表示せず、メールアドレス・パスワードによる本人認証を必須化しました。
2. **データベース側の完全ロック（Supabase RLS 強化）**:
   - 従来の開発用ポリシー（`using (true)`）をすべて廃止し、全5テーブル（`transactions`, `credit_cards`, `employers`, `expected_incomes`, `reimbursements`）に所有者ID（`user_id`）を追加して **`using (user_id = auth.uid())`** に変更しました。
   - これにより、万が一サイトのURLや公開キー（Anon Key）が外部に知られても、ログイン認証トークンを持たない通信はデータベース側で100%遮断されます。
3. **既存データの自動引き継ぎ（`claim_unowned_records`）**:
   - 認証導入前に登録していたカード・バイト先・収支・立替金などの既存データは、初回ログイン時に自動的にあなたのアカウント（`user_id`）へ紐付けられます。
4. **全データの登録後変更・編集 ＆ モダンUI（v5機能もすべて同梱）**:
   - 立替金・振込予定・カード引落日・年間明細などすべての登録データを後から編集可能。

## 🚀 セキュリティ強化の適用手順

1. Supabase の **SQL Editor** で `supabase/schema.sql` の内容を実行します。
2. `kakeibo-pwa-v6.zip` を解凍し、既存の `kakeibo-pwa` フォルダに上書きして GitHub にプッシュします。
3. 更新されたサイトを開き、「初回アカウント作成」からご自身のメールアドレス・パスワードを登録してログインします。
4. （推奨）ご自身のアカウント作成後、Supabase 管理画面の **Authentication > Providers > Email** で **「Allow new users to sign up」を OFF** にすると、第三者による新規アカウント作成自体も完全に禁止できます。
